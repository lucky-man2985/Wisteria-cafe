`/workspace/artifacts/wisteria-design-review/layout-check.json`.

браузерный прогон и готовит доставку; design_review даёт независимый визуальный
отзыв и создаёт intent/spec/plan/evidence. Одновременной записи тех же файлов нет.
Принимающий передачу — основной агент; пользователь принимает визуальное решение.

При возврате изменений удалять или исправлять только файлы WC-DESIGN-02 и
отдельный review-пакет после сравнения git diff. Не восстанавливать checkout
