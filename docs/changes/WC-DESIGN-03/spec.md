# Спецификация WC-DESIGN-03

Основание: intent.md. Дата: 15 октября 2026. Статус: требования текущего этапа.

Сценарий действующего сайта: прежняя главная с сохранённым H1 → исправленная
глициния и новый H2 в `.brand-pause` под карточками → прежние меню/карточки/корзина.
Отдельно: GitHub PNG и сравнение десяти направлений → выбор пользователя →
дальнейший перенос только выбранного направления. H1 концептов одинаковый:
«Вкус, к которому хочется вернуться.».

Источники истины: `/workspace/Wisteria-cafe`; состояние — plan.md;
доказательства — evidence.md. Контракт:
`/workspace/scratch/wisteria-design-03/CONTRACT.md`. База до исправления:
`/workspace/scratch/wisteria-design-03/before/` и `baseline.json`. Варианты:
`/workspace/artifacts/wisteria-directions-10/`. Локальные пути не доказывают
передачу пользователю.

| D03-03 | menu.json с 431 записью и все 462 исходных ассета, включая логотип и акварель, побайтово неизменны относительно 463 хешей baseline. Маршруты, canonical и redirects сохраняются; генеративная графика остаётся только в вариантах. Приёмка: SHA-256, сборка и verify_hosting. |

Диагноз до исправления: HTML `width=1145 height=1600`, CSS задавал только
width 300 / 155 px; высота 1600 и отрицательные смещения искажали и обрезали рисунок.
Теперь используется колонка в потоке, естественные размеры изображения,
без transform и позиционирования за краем панели.

Графика вариантов: `assets/wisteria-watercolor.png` и
`assets/wisteria-engraving.png`, PNG RGBA 1536×1024; источник по передаче root —
image_gen с исходной акварелью. Растягивание запрещено; на тёмной поверхности
оригинал находится на белой подложке, без multiply на тёмном фоне. Выдуманные
хиты, отзывы и диетические обещания не добавляются.

Ответственность: root объединяет, проверяет, передаёт и выпускает;
CSS01–03/CSS04–06/CSS07–09 ведут назначенные scoped CSS, root — направление 10.
Независимый design_review не редактирует проверяемое оформление.
