# Намерение WC-DESIGN-03

Дата: 15 октября 2026. Ответственный: root, основной агент текущего чата.
Процесс: «Джинн» 1.0.0, Standard.
Статус: исправление опубликовано; десять направлений прошли независимую
приёмку и переданы через GitHub. Поручение выполнено.

На существующей главной нужно было исправить искажение и обрезание акварели
в `.brand-pause` под карточками. Исправление сохраняет естественную форму
глицинии в отдельной колонке. Новый слоган «Вкус, к которому хочется вернуться.»
заменяет H2 именно этого блока. Живой H1 «У каждого дня свой вкус.» сохранён.

Вторая часть поручения — десять профессиональных направлений для выбора
следующего дизайна кафе с удобными меню, навигацией и карточками. Для честного
сравнения в десяти отдельных концептах новый слоган используется в H1 макета.
Новое направление не заменяет действующий дизайн до выбора пользователя.

Исправление существующего сайта разрешено текущим запросом и предыдущим
поручением на выпуск. Оно уже выпущено commit
`1ec9f05c88f5c1cdb2d0c020ea988550699486b3`:
https://lucky-man2985.github.io/Wisteria-cafe/.

Входит: исправленная колонка исходной глицинии, H2-слоган, десять композиций
home/menu на desktop/mobile, 40 PNG, две сравнительные доски и PDF на десять
страниц для просмотра. Генеративные акварель и гравюра применяются только
в вариантах. Итоговые изображения передаются через GitHub.

Границы: оригинальный логотип, исходная акварель, 431 запись меню, цены,
варианты блюд и маршруты сохраняются. Публикация одного из десяти направлений
без выбора, реальные заказы и оплата не входят в этап.

Исправление проверено локально и по HTTP после выпуска. Подготовлены40 PNG,
две доски и10-страничный PDF. Замечания независимого ревью исправлены и повторно
проверены. Публичные ссылки44 файлов открываются и побайтово совпадают
с локальными. [Материалы выбора](https://github.com/lucky-man2985/Wisteria-cafe/tree/design/wisteria-botanical-10-2026-10-15/botanical-directions).
Следующий выбор направления остаётся за пользователем; передача уже завершена.
