# Исходники утверждённого оформления Wisteria

Выпуск 15 октября 2026: https://lucky-man2985.github.io/Wisteria-cafe/
Публикуемая сборка: preview-design, commit 841e1af3bf02df7f8d0fb917bf8e35226bee36af.

Здесь сохранены полные версии изменённых исходных файлов. Это набор для переноса
поверх исходного архива сайта, а не самостоятельная копия всех данных проекта.
Скопируйте файлы с сохранением путей в корень распакованного проекта. Остальные
Python-модули, JSON, 431 запись меню и 462 ассета берутся из исходного проекта.

Сборка из корня проекта: `python3 build_pages.py`.
Для отдельного корня GitHub Pages: `python3 hosting/prepare_comparison.py --source dist --output /tmp/wisteria-pages --site-url https://lucky-man2985.github.io/Wisteria-cafe/`.
Сборка не публикует сайт автоматически.

brand-nav.js управляет раскрытием категорий и видимостью активного раздела.
Данные, цены, варианты и алгоритм корзины сохранены. Родной favicon — assets/logo.png.
